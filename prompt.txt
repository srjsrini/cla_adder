Implement a 32-bit combinational adder using carry look-ahead logic.

The design should compute carry bits using Generate and Propagate signals
instead of relying on ripple carry behaviour.

Inputs:
- in1[31:0]
- in2[31:0]
- carry_in

Outputs:
- sum[31:0]
- carry_out

The module must be purely combinational.

Avoid using the '+' operator.

The carry_out should represent the final carry produced by the addition.

Do not change the module interface.
